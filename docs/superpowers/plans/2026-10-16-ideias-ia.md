# Ideias e plano com IA — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Página "Ideias" com geração por IA (prazo, vídeos curtos, próxima semana) e "Pôr no calendário" como rascunho.

**Architecture:** Funções puras para datas (`plan-dates`), esquema/pós-processamento e prompts; `runIdeas` no serviço de IA existente (mesmo orçamento e registo); repositório + server actions finas; UI nova em `/ideias`.

**Tech Stack:** Next.js 16, Supabase (Postgres + RLS), zod 4, Vitest, Playwright, OpenRouter (cliente existente).

**Spec:** `docs/superpowers/specs/2026-10-16-ideias-ia-design.md`

## Global Constraints
- Texto visível em pt-PT. Datas/horas calculadas pela app no fuso da marca.
- Limites: título 120, gancho 300, guião 1500, legenda 2200; posts/semana 1–21 (omissão 3).
- Prazo: desvios −28, −21, −14, −7, 0 dias. Vídeos curtos: 10. `max_tokens` ideias: 3000.
- Mesmo orçamento mensal; `ai_usage.kind = 'ideas'`.
- Rascunhos só com contas **ativas**; nada é agendado/publicado automaticamente.

## Review Focus
1. Marca sem contas ativas → "Pôr no calendário" cria rascunho sem redes (não falha). Teste na Task 7.
2. Prazo hoje → 1 ideia com data de hoje (hora futura ou a próxima disponível). Teste na Task 3.
3. Semana já completa → erro claro, sem chamada à IA nem custo. Teste na Task 6/7 (lógica pura em Task 3).
4. IA devolve formato de outra rede / rede desconhecida → descartado no pós-processamento. Teste na Task 4.
5. "Todas as marcas" selecionado → botões pedem marca. Teste e2e na Task 9.

### Task 3: Datas do plano (puro)
**Files:** Create `src/lib/ai/plan-dates.ts`, test.
**Produces:**
```ts
export const DEADLINE_OFFSETS = [-28, -21, -14, -7, 0];
export function deadlineDates(dueDate: string, today: string): string[]; // datas ≥ today; [] se dueDate < today
export function nextWeekRange(now: Date, tz: string): { start: string; end: string }; // seg..dom seguinte
export function spreadWeek(start: string, n: number): string[]; // dia floor(i*7/n)
export function timeForDate(o: { date: string; goal: Goal; tz: string; history: HistoryPoint[]; busy: Date[]; now: Date }): string;
export function missingForWeek(postsPerWeek: number, alreadyPlanned: number): number; // max(0, …)
```
`timeForDate`: melhor faixa do histórico nesse dia (≥10 pontos, mediana ≥ global, como `best-time`) senão hora de `INITIAL_TIMES[goal][dia]` mais próxima das 19:00; salta horas a < 2 h de `busy` ou < 1 h de `now` (próxima da tabela; se nenhuma, a escolhida).
- [ ] Testes: desvios com hoje no meio; prazo hoje → [hoje]; prazo passado → []; semana a partir de quarta → seg..dom seguinte; fuso Cabo Verde; `spreadWeek(start,3)` → seg, qua, sex; `spreadWeek(start,5)`; hora sem histórico (19:00 em dia útil, 18:00 ao sábado); com histórico usa a faixa; evita ocupado; `missingForWeek(3,5) = 0`.
